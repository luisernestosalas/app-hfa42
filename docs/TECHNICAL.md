# Documentación Técnica - CRM App HFA42

## Información General

**Aplicación:** Sistema CRM para gestión de clientes y notas  
**Stack Tecnológico:** HTML + JavaScript (Frontend)  
**Repositorio:** https://github.com/luisernestosalas/app-hfa42  
**URL de Producción:** https://app-hfa42-5s97cz7ot-luisernestosalas-2775s-projects.vercel.app

## Descripción del Proyecto

Sistema de gestión de relaciones con clientes (CRM) desarrollado con tecnologías web estándar. La aplicación permite la administración de información de clientes y el manejo de notas asociadas.

## Arquitectura Técnica

### Frontend
- **HTML5:** Estructura y marcado semántico
- **JavaScript Vanilla:** Lógica de negocio y manipulación del DOM
- **CSS:** Estilos y presentación (implícito en stack web)

### Hosting y Deployment
- **Plataforma:** Vercel
- **Tipo de Deploy:** Estático/SPA (Single Page Application)

## Funcionalidades Principales

### Gestión de Clientes
- Registro de nuevos clientes
- Visualización de lista de clientes
- Edición de información de clientes
- Eliminación de registros de clientes

### Sistema de Notas
- Creación de notas asociadas a clientes
- Visualización de notas por cliente
- Edición de notas existentes
- Eliminación de notas
