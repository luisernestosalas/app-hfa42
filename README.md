# CRM App - Gestión de Clientes y Notas

Una aplicación web simple y eficiente para la gestión de clientes y sus notas asociadas, desarrollada con tecnologías web nativas.

## 🚀 Características

- ✅ **Gestión de Clientes**: Crear, editar y eliminar clientes
- 📝 **Sistema de Notas**: Agregar y gestionar notas por cliente
- 💾 **Almacenamiento Local**: Los datos se guardan en el navegador
- 📱 **Responsive**: Adaptado para dispositivos móviles y escritorio
- ⚡ **Rápido y Ligero**: Sin dependencias externas

## 🛠️ Tecnologías

- **HTML5**: Estructura y marcado
- **CSS3**: Estilos y diseño responsive
- **JavaScript**: Lógica de aplicación y manejo de datos
- **LocalStorage**: Persistencia de datos en el navegador
